https://github.com/powerline/powerline/blob/11808cbe5c16e4621edcaefa916b5add81eab799/font/PowerlineSymbols.otf

```text
4a2496a009b1649878ce067a7ec2aed9f79656c90136971e1dba00766515f7a1
```

`U+E0B0-E0B3`.
